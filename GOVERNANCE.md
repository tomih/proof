# Governance

PROOF was created by Hodl and is used in [Hodl Advisory's](https://hodl.org) approach to reviewing and designing consequential agent systems. Hodl remains the release authority.

## Canonical releases

A canonical release is published from the canonical repository with:

- an immutable version tag;
- the standard, fixture, field guide, and release documents;
- a release manifest and checksums;
- a publication date and canonical permalink.

A later release supersedes an earlier one only where the changelog says so; earlier public releases remain available as history.

## Changes

- Major versions contain incompatible contract changes.
- Minor versions add or materially strengthen requirements.
- Patch versions clarify without changing an obligation.
- Requirement identifiers remain stable within a major version and are not reused after retirement.
- A normative change identifies its rationale, affected requirements, and fixture evidence where relevant.

## Contributions and release authority

Anyone may propose corrections, examples, fixtures, or changes under `CONTRIBUTING.md`. Acceptance does not transfer release authority. Hodl remains the release authority unless a later canonical governance release explicitly changes that arrangement.

## Claims

PROOF 0.3 does not define certification, assessor accreditation, or badges. Modified works must not imply review, endorsement, or approval by Hodl.
